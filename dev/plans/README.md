# Working Plans

Multi-session plans for developing the Purlin framework itself, checked in so they survive a
handoff to another machine or another agent.

A plan here is a **living record**, not a proposal: each phase gets a `## DONE` section naming the
commits that delivered it and the adjacent defects it turned up, written as the phase lands. The
`## Execution notes` at the end of each plan carry the environment traps that cost real time, and
are the first thing to read before picking one up.

These are working documents, not part of the framework contract. `purlin:drift` and the specs do
not track them, and nothing under `dev/` ships to consumer projects (see the root `CLAUDE.md`,
"Tool Folder Separation").
