## Outputs

- `scripts/anchor/upstream.py` (~200 lines, stdlib only), a CLI and a module:
  `add <git-url> --path <file> [--name <name>]` (fetch the file at the remote default
  branch's head with a shallow clone into `.purlin/runtime/anchors/`, write
  `specs/_anchors/<name>.md` with `> Source: <url>/<file>` and `> Pinned: <sha>`; a
  free-text source is written as the copy with a note that the rules are to be drafted, the
  AI drafting itself is the skill's job); `sync [name|--all] [--check] [--json]` (one cached
  `ls-remote` per pin, fetch, rule diff printed as "RULE-3 changed, RULE-6 added", copy the
  designs the source references into `designs/<anchor>/`, advance the pin; `--check` only
  reports, exit 1 when any pin is behind; `--json` for the skill and the scheduled job);
  `propose <name>` (write the patch the anchor repo needs to
  `.purlin/runtime/anchors/<name>.patch` and print the `gh pr create` or ADO command the
  person runs). Pins are commits, never branches. `--project-root DIR` everywhere.
- `dev/test_upstream.py` (target 400): two local bare repos (an anchor repo and a project),
  add, sync when behind, `--check` exit codes and JSON, design copy, propose, the free-text
  source note; no network.
- `dev/test_e2e_external_refs.sh` and `dev/test_e2e_anchor_authority.sh` rewritten against
  `upstream.py` and the package's drift output, `dev/setup-external-refs.sh` adjusted so the
  local bare repo it creates carries a 0.10.0 anchor (no `figma://`, no visual hash).
