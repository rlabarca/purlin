# Lane 9H: the three hand-run CLI checks

Design: dev/plans/evidence-workflow.md (read in full; A3, A6, A10)
Rules: dev/plans/lanes/_rules.md (read in full)

## What these are

Three scripts a person runs by hand, never from `dev/run_tests.sh`, each driving the real
`claude` CLI once against a temporary project with this checkout loaded as the plugin
(`claude --plugin-dir /Users/richlabarca/LocalCode/purlin -p "<prompt>"`), then printing
what to look at. They replace the deleted model-driven tests. Each spends money, so each
runs one prompt, with a hard timeout, and prints the transcript path.

## Outputs

- `dev/manual/check_spec.py` (~120 lines): a temp git repo with `purlin:init` answered
  `tested` through `scripts/init/scaffold.py --gate tested --yes`, then one `claude -p`
  invocation asking `purlin:spec` to write a spec from the sentence in A10 ("Users sign in
  with email and password. After five failed attempts the account is locked for fifteen
  minutes."). Prints: the spec file written, its rule count, whether every rule carries a
  proof, the tags, and whether the reply ends with "Build it now?".
- `dev/manual/check_build.py` (~140 lines): the same project after `check_spec`'s spec is
  written (or a committed fixture spec of two rules if the caller passes `--spec <file>`),
  one `claude -p` asking `purlin:build login`. Prints: the files created, whether the tests
  carry proof markers, the result of `scripts/run/purlin_run.py --all --quick`, and the
  commit body's three sections.
- `dev/manual/check_qa_tool.py` (~100 lines): packs `tools/QA/purlin-qa-report.md` and runs
  one `claude -p` with the tool's text as the system prompt against
  `scripts/report/scan.py --repo <this checkout>` output, asking for the triage report.
  Prints: the report, and whether it is ordered by risk and names the review list only.
- `dev/manual/README.md` (10 lines): what each check is for, how to run it, that it spends
  money, and that nothing here is in the sweep.
- Each script: `--keep` leaves the temp project for inspection; `--timeout` (default 600 s);
  exits 0 when the CLI ran and the printed checks passed, 1 when a check failed, 2 when
  `claude` is not on PATH (with the one-line reason).
