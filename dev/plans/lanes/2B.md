## The interface lane 2A calls (write exactly this; 2A's run script imports it lazily)

```python
# scripts/run/mutation/__init__.py
select_engine(config, frameworks) -> str          # 'stryker' | 'stryker_net' | 'mutmut' | 'none'
run_breaks(project_root, engine, scope_by_feature, tests_by_rule, tier) -> dict
# returns {"engine": str, "available": bool, "reason": str,
#          "features": {feature: {"scope_score": {"score", "killed", "survived"},
#                                 "rules": {"RULE-N": {"engine", "score", "killed",
#                                                      "survived", "attribution"}}}},
#          "log": str}
# scope_by_feature: {feature: [scope file paths]}; tests_by_rule: {(feature, "RULE-N"):
# [{"file", "name", "plugin"}]}; attribution is "per_test" | "per_scope" | "unavailable".
# score is an integer percent; killed / (killed + survived); timeouts count killed;
# NoCoverage counts survived for the scope score.
```

`config` is the project's `.purlin/config.json` dict (`mutation_engine` is `"auto"` or an
engine name); `frameworks` is what `scripts/mcp/purlin/frameworks.py` detected. `auto`
picks Stryker for jest or vitest, Stryker.NET for xunit, mutmut for pytest, `none` for
shell and sql, and `none` with `reason` when the engine binary is not installed.
